▸ Come configurare la API key su Netlify
huggingface.co/settings/tokens → New token → tipo Read → copia.
Su Netlify: Site configuration → Environment variables → key HUGGINGFACE_API_KEY → scope All → Trigger deploy.

Servono anche SUPABASE_URL e SUPABASE_ANON_KEY per verificare l'autenticazione.

🎨 Canva
Collegando Canva puoi:
→ Importare template dal tuo account come base per i piani
→ Usare Bulk Create: esporti il piano come CSV, lo carichi in Canva e crea automaticamente tutti i post da un template
→ Accedere al Brand Kit: colori, font e loghi del cliente collegati
→ Salvare i design direttamente nel tuo spazio Canva
▸ Come configurare Canva
Richiede Canva Pro/Teams. canva.com/developers → Nuova integrazione → Scopes: design:content:read design:content:write asset:read asset:write brandtemplate:content:read folder:read → Redirect URI = URL del tuo sito → Genera token OAuth2

Alternativa senza API: esporta come CSV → Canva → Bulk Create → scegli template → importa CSV → tutti i post vengono generati automaticamente.
